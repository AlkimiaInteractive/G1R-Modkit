sidebar:

---

Adds a new language translation called "gibberish" to the game. Replaces some of the main menu texts, falls back to english otherwise.

The new language can be selected in the game options as usual (defined via the LanguageSet in `Game.ini`).
[View this example on GitHub](https://github.com/AlkimiaInteractive/G1R-Modkit/tree/main/Examples/Example-NewLanguageTranslation)
