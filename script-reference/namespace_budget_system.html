bool BeginHighPriorityTickRequest ( const UObject Context,

Requests time for a ticking update of the given context object. If this returns true, be sure to also call EndTickRequest().

Example: 

if (BudgetSystem::BeginHighPriorityTickRequest(this, n"MyWorkload"))
{

Do heavy calulations 

    BudgetSystem::EndHighPriorityTickRequest();
}
