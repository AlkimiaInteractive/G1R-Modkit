Detailed Description

A single gameplay tag, which represents a hierarchical name of the form x.y that is registered in the GameplayTagsManager You can filter the gameplay tags displayed in the editor using, meta = (Categories = "Tag1.Tag2.Tag3")).

FGameplayTag GetParentAtHierarchyLevel ( int Level) const

Returns a Parent GameplayTag that has only the specified amount of hierarchy levels (at most).

Level 0 will always result in the EmptyTag. Level 1 will always result in the Root tag.
