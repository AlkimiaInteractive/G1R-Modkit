Uses a WorldPoint Extension to 

 * change an existing item spawner to spawn a different item,
 * place a new single pickable items into the World,
 * add a new randomized multi-item spawner.


[View this example on GitHub](https://github.com/AlkimiaInteractive/G1R-Modkit/tree/main/Examples/Example-ItemSpawner)
