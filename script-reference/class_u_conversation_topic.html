Detailed Description

Represents a single conversation topic, ie. a choice that the player can choose in the UI or something that an NPC wants to talk about once you get near them.

It contains the "stage directions" of how the conversation should play out: Who says what, which actions to perform, etc.

Additionally, it provides a set of rules and conditions that need to pass for this topic to be available to the player to choose or an NPC to come forward with it.

@note These objects are not supposed to be modified at runtime.
