Detailed Description

Persistant state for each character. Is kept alive always, even when the character pawn is not spawned. Also keeps track of whether the character pawn should be visible and spawns it as needed.

This actors transform will match the characters pawn while it is spawned. Otherwise, it will represent where the character pawn should be right now by simulating their daily routine if there is one.
