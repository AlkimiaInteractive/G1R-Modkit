UBehaviorTree BehaviorTree,
FVector Location,
FRotator Rotation = FRotator ( ),
bool bNoCollisionFail = false,
AActor Owner = nullptr )

Spawns AI agent of a given class. The PawnClass needs to have AIController set for the function to spawn a controller as well.

Parameters
BehaviorTreeif set, and the function has successfully spawned and AI controller, this BehaviorTree asset will be assigned to the AI controller, and run.
Ownerlets you spawn the AI in a sublevel rather than in the persistent level (which is the default behavior).
