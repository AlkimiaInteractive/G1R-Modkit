Detailed Description

Nico Version.

Set of rules for a conversation topic. This represents the static flow of topics, without any dynamic script conditions.

Determining whether a topic is supposed to be visible follows these stages: 

1.  EnableIfKnowsAnyOfInFull is an Array containing multiple Knowledge Sets.
        if the Input Knowledge Set includes ALL Knowledges contained in ANY of these
        Sets it passed the first check. It may still be excluded by the following
        checks.

2.  DisableIfKnowsAnyOfInFull is an Array containing multiple Knowledge Sets.
        if the Input Knowledge Set includes ALL Knowledges contained in ANY of these
        Sets it's not valid, even if it passed other checks.
  1. Lastly, check for dynamic script conditions.

If those are satisfied, the topic may be shown to the player.
