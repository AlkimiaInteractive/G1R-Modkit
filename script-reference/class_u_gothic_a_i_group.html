Detailed Description

Subclass to define your own kind of groups. Each character can be in multiple groups in the same time. The UAIGroupStatus object allows to share information between the characters of the group. This is helpful whenever more than two character need to interact with each other for a while.

Example:

  • Fighting as a pack
  • Standing in a queue

Subclass this to add your own groups and information!
