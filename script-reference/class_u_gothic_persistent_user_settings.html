Detailed Description

this is a wrapper around the UGothicGameUserSettings object that allows us to store the data to a savegame slot this is done similar to Lyra and we need it so that we can satisfy PS5 and Xbox requirements. instead of manually storing the properties we simply store the config ini contents as a string and put that back into the config system
