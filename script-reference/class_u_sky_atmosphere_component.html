USkyAtmosphereComponent Class Reference
Engine » Engine

A component that represents a planet atmosphere material and simulates sky and light scattering within it. @see https://docs.unrealengine.com/en-US/Engine/Actors/FogEffects/SkyAtmosphere/index.html. More...

Detailed Description

A component that represents a planet atmosphere material and simulates sky and light scattering within it. @see https://docs.unrealengine.com/en-US/Engine/Actors/FogEffects/SkyAtmosphere/index.html.
