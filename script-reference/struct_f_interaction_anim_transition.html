Detailed Description

Represents a simple transition of an interaction montage as used in UAbilityTask_InteractionSpot_Montage.

It defines the transition as FromSection and ToSection. Whenever a transition is to be activated, it either blends between two different montages, or - on a seamless transition - the next section that FromSection (usually Loop) would play is replaced with whatever is written inside ToSection. That way, the Loop-section does not loop, but plays the given ToSection instead.

Additionally, it allows to configure various cooldown times for this specific transition and others.
