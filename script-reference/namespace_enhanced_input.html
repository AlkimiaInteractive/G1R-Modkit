◆ RequestRebuildControlMappingsUsingContext()

void RequestRebuildControlMappingsUsingContext ( const UInputMappingContext Context,
bool bForceImmediately = false )

Flag all enhanced input subsystems making use of the mapping context for reapplication of all control mappings at the end of this frame.

Parameters
ContextMappings will be rebuilt for all subsystems utilizing this context.
bForceImmediatelyThe mapping changes will be applied synchronously, rather than at the end of the frame, making them available to the input system on the same frame.
