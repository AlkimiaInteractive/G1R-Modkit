Detailed Description

Detects whether a location is "indoor" or "outdoor" by performing AmbientOcclusion-style sampling by shooting Traces in random directions of a hemisphere.

Each trace contributes to the final score that

  • if negative means "outside"
  • if positive means "inside"

You can weight each trace by whether it was going up towards the sky/ceiling or sideways against a wall.

For example, you may want to boost "outdoorness" whenever the sky is visible, so you could just increase the score for traces that go upwards and did not hit anything.

The sampling is done asynchronously, the results should come in 1-2 ticks later.

@note There is a component that wraps this (UIndoorDetectionComponent). For individual queries, just using the struct will probably be simpler though.

Example: 

FIndoorDetectionSampler IndoorDetection;

IndoorDetection.NumSamples = 5000;
IndoorDetection.SweepTraceSphereRadius = 10.0f;

IndoorDetection.ScoreWeight_Indoor_EnclosedByWalls = 1.0f
IndoorDetection.ScoreWeight_Indoor_HasRoof = 2.0f
IndoorDetection.ScoreWeight_Outdoor_NoWalls = 32.0f
IndoorDetection.ScoreWeight_Outdoor_VisibleSky = 32.0f

IndoorDetection.QueryParams.AddIgnoredActor(SomeActor);
IndoorDetection.QueryParams.AddIgnoredActor(SomeOtherActor);

IndoorDetection.RequestAsyncSampling(
    this,
    SomeLocation,
    FIndoorDetectionResultDelegate::CreateUObject(this, &ThisClass::HandleIndoorDetectionResultsAvailable)
);
