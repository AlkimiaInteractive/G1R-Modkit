Detailed Description

This GE can be applied whenever we want to kill a character imediatly. It's a copy of UGameplayEffect_PlayerKilledHimself by BFG.

  • Sets the health attribute to zero and add a special tag to pass checks in UAttributeSet_Health::ShouldCharacterDie()
  • Skips the defeated state
