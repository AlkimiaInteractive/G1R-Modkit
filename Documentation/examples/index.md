Check the `Examples/` folder for small self-contained mod examples on how to do certain things, like:

 * **Example-HelloWorld:** How to get a simple new script file loaded into the game.
 * **Example-ItemSpawner:** How to add new pickable items into the world.
 * **Example-CharacterSpawner:** How to spawn a character into the world (existing character type).
 * **Example-ChestContents:** How to modify an existing chests contents.
 * **Example-DiegoConversation:** Adds a somewhat complex new conversation option to Diego.
 * **Example-LocalizationOverride:** Changes the localized text for an existing language.
 * **Example-NewLanguageTranslation:** Adds a new language translation to the game.
 * **Example-NewHumanCharacter:** Adds a new character that can be spawned and interacted with.
 * **Example-NewSword:** Adds a new kind of Sword to the game.
 * **Example-Settings:** Injects mod related settings for players to change into the "Game" options.
 * **Example-StatsPage:** Shows how to modify UMG UI Widgets via AngelScript (puts additional info into the character stats widget)
 * **Example-StartupLevel:** Changes the level that is loaded when starting the game to a mostly empty level (Cube, Playerstart, Sky)
 * **Example-BlueprintVariant:** Shows how to extend BlueprintAssets (Adds a FireSword based on an existing other swords visual Blueprint)
 * **Example-NewGameplayTag:** Registers a new GameplayTag through config and uses it from a script.
