Detailed Description

Struct that keeps track of how many LooseGameplayTags were added to an AbilitySystemComponent.

Simplifies making sure that you don't remove tags added by other abilities by accident and keeps you from adding the same tag multiple times.

@example To use, create a member variable of this struct like so: 

         FOwnedLooseGameplayTags OwnedLooseTags;

     Then later, add a tag like so:

         OwnedLooseTags.AddTagIfNeeded(this, GameplayTag::MyTag);

     And at a later point, remove the tag that you added like so:

         OwnedLooseTags.RemoveTagIfNeeded(this, GameplayTag::MyTag);

@note It is important to remove the tags, they will not be removed automatically! (See RemoveAll) @note Always pass the same ASC to the functions. Don't use the same struct on different ASCs!
