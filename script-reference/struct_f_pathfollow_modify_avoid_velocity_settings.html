Detailed Description

Pathfollowing settings about how an agent should modify its velocity, when other agents are nearby.

Default crowd avoidance behaviour makes agents slow down to make them walk around each other carefully. Often however we want to increase their speed instead, so that avoidance behaves like quick dodging.
