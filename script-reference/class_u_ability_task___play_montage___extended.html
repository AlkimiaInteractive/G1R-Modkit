◆ GetCurrentSectionPlayedRatio()

float32 GetCurrentSectionPlayedRatio ( ) const

Returns a number between 0 and 1 showing how far we are into the current montage section.

A number close to 0.0 means that the section has just started. Numbers close to 1.0 mean that the section is about to end.

On looping sections, a ratio that is less than it was last frame means that the section looped. Keep in mind that this could lead to unexpected behavior if the frame takes longer than the animation section!

◆ GetSectionPlayedRatio()

float32 GetSectionPlayedRatio ( FName section) const

Returns a number between 0 and 1 showing how far the given section has been played.

If the montages current position is...

... before the given section, 0.0 is returned ... in between the given sections start/end, the ratio of how far we're into the section is returned. ... after the given section, 1.0 is returned

If an error occured or the montage is not playing for some reason, 0 is returned.

◆ GetSectionPlayedRatioAtPosition()

float32 GetSectionPlayedRatioAtPosition ( FName section,
float32 position ) const

Returns a number between 0 and 1 showing how far the given section has been played at the given position. The position should be the seconds from the start of the montage. If the given position is not inside the given section, the returned value is as follows:

0.0 if the given section has not started yet (position is before the section starts) 1.0 if the given section has been fully played and the given position is somewhere after the sections end time.

If the montage is not playing or some other error occurred, 0 is returned.
