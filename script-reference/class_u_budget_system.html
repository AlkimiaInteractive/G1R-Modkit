◆ ProcessPendingWorkUntilBudgetIsReached()

int ProcessPendingWorkUntilBudgetIsReached ( FName WorkloadName)

Executes enqueued work for the given workload as long as there is budget to do so.

Note: All workloads automatically do this at the end of the frame. Use this function if you want to trigger this behavior manually at a certain place in the code. This is useful if you want to have some tasks be processed immediately if possible.

Returns
How many enqueued tasks were done.
