◆ SelectMatchingMoreSpecificAction()

FGameplayTag SelectMatchingMoreSpecificAction ( FGameplayTag Action) const

If this spots only supports actions that are more specific than the given action, this function will return actual action to do.

For example, when this Spot only accepts Action.Sit.Ground, and you pass in Action.Sit (which is a valid thing to do), it returns Action.Sit.Ground.

Returns EmptyTag if tag of the PossibleActions matches.

Note: The first matching tag encountered is returned. No random selection.
