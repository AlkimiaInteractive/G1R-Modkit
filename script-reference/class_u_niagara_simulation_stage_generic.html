void SetbParticleIterationStateEnabled (bool Value)
 When enabled we iterate over the subset of particles that satisfy the binding & range selected. For example, if the binding was set to Particles.MyStateIndex and the range was 1-3 only the particles with values of 1, 2 or 3 for Particles.MyStateIndex would run the script, all others would be ignored.
