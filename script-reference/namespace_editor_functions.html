void DoSetDistanceFieldResolutionScaleToAllSceneMeshes ( float32 NewDFResolutionScale)

This function will get all the scene mesh actor and set the distance field resolution scale. The function was created to avoid that the particles get stuck on meshes. Like sword or floating runes. (Small Items) NOTE: This must be used in an empty map.
