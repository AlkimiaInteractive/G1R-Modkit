bool bStrafeTurnToPotentialBlockingAgent
 When there is an agent that we need to avoid (moving), start strafing and turn body and head towards him. Helps to prevent turnarounds when starting to move close to other agents or when we are running into others. Note that quadrupeds are not able to strafe, which might cause them to run into each other.
